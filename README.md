# ICEY FABULASH

Christopher Reyes

This project is a single-page authentication UI for ICEY FABULASH with a responsive split-panel layout. The page uses HTML, CSS, and vanilla JavaScript to present a login and signup experience with client-side validation, password visibility toggles, and a polished beauty-brand aesthetic.

The implementation approach is to keep the front-end lightweight and accessible: use semantic form structure, Bulma for baseline styling, custom CSS for the brand look, and targeted JavaScript for panel switching, validation, error messaging, and password-toggle behavior.
